# Viewer stage

The viewer inherits the full-width Studio direction: the real object leads, and tools become visible when asked for. This is an Experience surface with precise Operate controls. The saved geometry and engineering evidence are authoritative; presentation is not a new material or strength claim.

- Fill the available stage. Keep an open, quiet background and a compact lower tool rail.
- Use a neutral display material initially. Preserve the original per-part identity colors as an explicit View option; do not alter data or exported geometry.
- Open one contextual tool tray at a time; return to the object with its Close button or Escape. Phone trays occupy only the lower part of the stage and scroll internally.
- Preserve parts, joints, cut-away, stress, comparison, assembly steps, shopping, print and checks. Keep real warning and failed-check access visible even while trays are closed.
- View settings are disclosures with named controls, keyboard focus and reduced-motion support. Model gestures have a Help disclosure.
- Studio can render compatible saved mesh data using the current template. Unsupported saved formats retain their original self-contained viewer; saved exports are never rewritten.

Validation uses existing saved geometry and synthetic browser fixtures. Desktop and phone in light and dark are inspected in one batch, corrected together, then confirmed once. No project build or FEA is part of this change.

First inspection used the saved FPV wing (38 meshes, two joints), both themes at 1512×982 and 390×844. It found too much sphere-fit padding and a phone tray covering the whole object. The correction fits the projected bounding box and gives the renderer a separate visible area beside or above an open tray. The original file was only read. The embedded caption yields to Studio's project heading; the warning control stays visible. The one mechanical detector warning is the inherited range of small engineering-text sizes, not a missing display headline: the object is this surface's headline.
